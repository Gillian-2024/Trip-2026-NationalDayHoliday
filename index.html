证件与通关

港澳这两段都不需要买票

  • 深圳 ⇄ 香港：走陆路口岸（福田进 / 罗湖出）。拿港澳通行证排队过关，不预约、不买票（2023 年起已取消口岸预约制）。过完是香港侧地铁站，刷八达通进站。
  • 珠海 ⇄ 澳门：走横琴口岸（24 小时），刷证 + 采生物特征过关，不买票。过完轻轨在口岸地底，现场买票。
  • 要提前准备的只有两样：港澳通行证 + 港、澳两次签注（⚠️ 是分开的两次），和一张八达通。
  • 这两天的景点全免费，没有可下单的东西。

香港（10/2）· 走陆路口岸

  • 出发前确认：港澳通行证在有效期内，且香港签注有效（一次即可）。
  • 去程 · 福田口岸（6:30 开闸）：跟着人流排队 → 刷证 + 按指纹 → 过完是香港侧的落马洲站。不需要预约、不需要买票。
  • 落马洲站刷卡进站（八达通或支付宝乘车码）→ 东铁线 → 红磡 → 换屯马线 → 尖东站。
  • 回程 · 罗湖：中环 → 红磡 → 东铁线 → 罗湖站 → 出站过关 → 罗湖口岸 → 1 号线直达会展中心。
  • ⚠️ 入境时发的白色小纸条随身带着，别丢。

澳门（10/4）· 横琴口岸往返

  • 出发前确认：澳门签注有效 —— 它和香港签注是分开的两次，缺一个就去不了那一天。
  • 去程：横琴口岸 24 小时，走旅检大厅，合作查验、一次放行 —— 只排一次队、读一次证、采集一次生物特征。
  • 过完在澳门侧，轻轨横琴站就在口岸地底，下扶梯即到。
  • ⚠️ 澳门轻轨自助售票机只收澳门元现金；客服中心可刷支付宝/微信/信用卡；莲花站 2026-09 起已换新闸机，可能已能扫乘车码，到站看一眼。路线：横琴站 → 莲花站 → 站内换氹仔线 → 妈阁。
  • 回程：氹仔海洋大马路 → 步行至轻轨海洋站 → 莲花站 → 横琴站 → 过关回珠海。

交通卡

香港 · 八达通（最该提前办的）

  • iPhone：钱包 App → 添加交通卡 → 搜「八达通」→ 直接开卡充值。地铁、巴士、天星小轮、便利店都能刷。
  • 或买实体租用版八达通：实付 HK$200（按金 50 + 首次储值 150）。⚠️ 落马洲站、罗湖站不发售——正好是你这次进出香港用的两个站，所以优先用 iPhone 钱包开卡。
  • 不支持八达通的地方用支付宝乘车码（走紫色闸机，扣人民币）。
  • ⚠️ 别买 HK$75 的「游客全日通」——落马洲站买不到，且不覆盖罗湖/落马洲段。

内地三市

  • 深圳 / 上海 / 广州地铁：用微信乘车码（深圳的支付宝可用性查不到官方来源，别赌）。
  • 上海地铁按次付即可——9/27、9/28 各约 4 段、合计约 ¥12–14，不到 ¥18 一日票的价，不用买。

澳门

  • 轻轨：车站自助机现场买票，不能用乘车码。
  • 公交：现金 MOP 6（不设找续、自备零钱、可用港币），或支付宝/微信扫码 MOP 6。

上网

  • 港澳用 eSIM 最省事（淘宝 ¥7.5 起，或买运营商境外流量包）。境外流量一般是「识别到你入境后才开始计时」，可提前买好。
  • 香港预付费实体卡自 2022 年起需实名登记；eSIM 不用。
  • 港澳导航用 Google Maps 比高德准；澳门巴士可配 DSAT App 看报站。

装备

  • 证件：港澳通行证（含港、澳两次签注，是分开的两次）+ 身份证原件。证件拍照存手机 + 发一份到自己邮箱。
  • 现金：港币（天星小轮、部分小店只收现金）· 澳门币（公交 MOP 6 不设找续、可用港币）· 人民币少带。三地合计约 1000–1500 元等值够用。
  • 充电宝——港澳一天十几个小时在外，必带（20000mAh 以内可上飞机）。
  • 转换插头：香港用英标 G 型三脚，澳门多为英标 + 欧标混合。酒店一般会提供，自己带一个更稳。多口充电头 + 数据线（两人共用）。
  • 薄外套：太平山顶风大，日落前后温差明显；跨境车厢与商场冷气也足。
  • 好走的鞋——每天 7–15 公里。澳门疯堂斜巷有坡度，别穿新鞋。伞：10 月初华南仍在雨季尾。
  • 小三脚架：珠海日月贝拍海面倒影、澳门烟花都要用。提前熟悉手机夜景模式（卢吉道、外滩、龙环葡韵都是弱光）。
  • 常备药：肠胃药、感冒药、创可贴（脚容易起泡）、晕车药。
  • 进教堂（石室外观、圣老楞佐堂等）不能短裤短裙、无袖、拖鞋。

  • 10/6 上午 · 越秀公园 + 中山纪念堂：五羊石像、明代城墙、镇海楼（广州博物馆）都在越秀公园内，免费；中山纪念堂（外观）就在旁边。这一段是广州老城的另一条轴线，2 号线纪念堂站一带，和 10/5 的西关—沙面完全不重复。
  • 10/6 中午 · 泮塘五约 + 荔湾湖公园（免费）：900 年清代古村落，广州历史城区里唯一保留完整清代格局的聚落。荔湾湖大戏台常有免费粤剧（下午 2:15–4:45）。

风险与备选

按发生概率排

台风 —— 唯一可能推翻整天安排的风险

  • 9/27 实查（香港天文台展望 + 广东 7 天预报）：西北太平洋确有一个热带气旋在发展，三种路径情景里「转向日本」「靠近台湾及广东东部后减弱」两种可能性稍大，目前没有直接影响华南的预报。东北季候风 10/1 起影响华南，高温会缓解。
  • 真正要盯的是雷暴，不是台风。广东 7 天预报：10/1 雷暴（12.6mm）· 10/2 雷暴（47.7mm，最重）· 10/3 雷暴（8.4mm）——D5 大梅沙 / D6 香港 / D7 珠海 这三天都在雷雨里，各天避坑里都写了替代方案。
  • 澳门 10/4 的烟花遇雷暴可能改期或取消——出发前查澳门旅游局官方公告。八号风球下横琴口岸、拱北口岸、港珠澳大桥会同时停摆。
  • 应对：9/29–9/30 再重查一次。若真有台风，澳门段可整体前移到 10/3（珠海那天本来就是半天机动）。台风导致列车停运可 30 天内全额退票；航班取消属天气不可抗力，享有免费退票或改签的法定权益，特价票同样适用。

10/6 赶飞机

  • 硬性时限：17:00 前必须离开大良（走城际）；走机场大巴（大良候机楼，正常 70–90 分钟、国庆按 150–180 分钟预留）则 16:00 前必须上车。

期望

这次没排进，但值得单独留一次

这些地方都符合你的口味——人文、自然、慢逛——只是这 10 天的动线装不下。留个底，下次直接从这里挑。

上海

  • 上海博物馆东馆（青铜馆）　免费、散客免预约（身份证从 B1 东门刷证入馆），10:00–18:00、17:00 停止入场、周二闭馆——它是上海唯一周一开的大馆，只有你 9/28 那天能去。但代价两条：① 它从 9/28 起书法馆、绘画馆、海上书画馆闭馆调整，那天剩下的主要是青铜（商周文明，不是上海）；② 免预约＝没有客流闸门，周一叠中秋假期尾，可能很挤。要它就要砍掉整条衡复步行。
  • 中华艺术宫 / PSA 当代艺术博物馆　常设展都免费。PSA 由发电厂改造，建筑本身就是内容。
  • 上博人民广场馆（¥148）· 浦东美术馆 MAP（¥100–150）· 龙美术馆西岸馆（¥180–220）　这三个是上海真正有分量的特展，代价是票价。
  • 朱家角 / 七宝老街　水乡。朱家角单程 1.5–2 小时，要占大半天。
  • 衡复的另外半张脸：黑石公寓、衡山坊——都在你走过的路上，只是没停。

深圳

  • 光明区　深圳科学技术馆（¥50）+ 光明农场大观园 + 光明招待所乳鸽——官方把"上午科技馆 → 下午虹桥公园 → 晚上乳鸽"定为一条经典微度假线。单程 45–60 分钟。
  • 南澳第一沙滩 · 大鹏半岛　较场尾、大鹏所城。⚠️ 自驾须在「深圳交警」公众号预约通行（3.3 万/日配额）——是深圳少有的"要抢"的地方。
  • 南头古城　免费，深圳少有的古城改造街区，人文向。
  • 深圳湾日出剧场　深圳唯一的真海上日出机位（面东）。要 5:00 起。

香港

  • 香港故宫文化博物馆（HK$70）· M+ 博物馆（HK$190）　西九这两馆是香港近年最重要的文化设施。代价是票价 + 至少 2.5 小时。
  • 大屿山　昂坪 360 缆车 + 天坛大佛 + 大澳渔村（水上棚屋，香港最后的水上人家）。要一整天。
  • 离岛　南丫岛、长洲——从中环坐船，是香港完全另一副样子。各需半天到一天。
  • 赤柱 / 石澳 / 龙脊　港岛南岸的海与山，龙脊是亚洲最佳市区远足径之一。
  • 庙街夜市 · 中环街市 · PMQ 元创方　市井与设计。中环街市就在 D6 半山扶梯的起点旁、PMQ 与大馆同在中环半山（相距数百米）——顺路可看；只有庙街夜市是真反方向。

珠海

  • 外伶仃岛 / 东澳岛　珠海最独特的东西。⚠️ 必须住岛上——去程船最早 08:40，回程末班 16:15–17:50，一日往返物理上不可能。
  • 唐家湾古镇 + 会同村 + 共乐园　民国首任总理唐绍仪的故乡，珠海最有底蕴的一片老村。在高新区，离市区约 20 公里，与情侣路反方向。
  • 北山村　市区里的文艺小村，免费。顺路但价值低于情侣路。
  • 淇澳岛红树林 · 斗门古街 · 梅溪牌坊　都在西区或离岛，各需半天以上。

澳门

  • 路环市区　澳门最慢的一站：安德鲁饼店本店、圣方济各圣堂、十月初五马路、荔枝碗船厂遗址。步行街区约 800 米、巷弄宽仅 1.5–3 米。这次它和烟花占位直接冲突。
  • 澳门博物馆（MOP 15，在大炮台上）· 大赛车博物馆（MOP 80，东望洋街道赛是澳门独有记忆）· 澳门艺术博物馆 / 通讯博物馆（免费）
  • 澳门科学馆　贝聿铭设计，建筑本身就是看点。
  • 摩珀斯　已经列在 D8 的「建筑有看头」里了，那天顺路进中庭即可。

广州

  • 陈家祠（¥10）　广州最有代表性的岭南建筑。闭馆日是周二，10/5 周一其实开——只是你那天已经排满西关。
  • 广东美术馆新馆（白鹅潭）　免费、双节期间开到 21:00、11 场展览，10/5 周一法定节假日照常开。它离沙面只隔 1 站地铁，是我这次砍掉的（室内展品与"拍照"弱相关）。
  • 广州艺术博物院 + 广东省博物馆　国庆期间同期有"城脉千年""一念敦煌""青州微笑"等重磅展，粤博免费但需提前预约。
  • 越秀公园 + 镇海楼（广州博物馆）+ 中山纪念堂　广州老城的另一条轴线，和西关—沙面完全不重复。
  • 黄埔古港 · 沙湾古镇 · 白云山　各需半天。

顺德

  • 逢简水乡　明远桥、进士牌坊、游船（小船 ¥150 / 大船 ¥250）。水乡感最强的一站，但要单独一个半天——和清晖园+华盖路三选二。
